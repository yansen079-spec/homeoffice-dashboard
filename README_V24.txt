1. Jalankan SQL_SETUP_V24_MARKETPLACE_LISTINGS.sql di Supabase -> SQL Editor -> New query -> Run.
2. Upload semua isi folder ini ke repository GitHub Pages yang sama.
3. Seller buka seller.html -> Katalog Produk -> Jual Produk -> isi harga & deskripsi.
4. Listing seller tampil publik di marketplace.html.
5. Seller dapat pause/tayangkan listing sendiri.
6. Seller tidak dapat mengubah stok asli HomeOffice.
7. Marketplace publik hanya mendapat field aman melalui RPC get_marketplace_listings().
