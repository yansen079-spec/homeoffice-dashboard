HOME OFFICE V16 - PAYROLL HARIAN 30 HARI

Sistem:
- Setiap karyawan punya daily_salary sendiri.
- Hari dibayar hanya jika check_in DAN check_out terisi.
- Periode payroll tanggal 1 sampai 30.
- Tanggal 31 tidak masuk payroll periode tersebut.
- Gaji Kotor = Hari Dibayar x Gaji Harian.
- Gaji Bersih = Gaji Kotor - potongan.
- Terlambat / Izin / Sakit / Cuti mengikuti nominal V15.
- Bos dapat Edit Gaji Harian per karyawan.
- Slip gaji mengikuti payroll harian.
- Semua fitur V15 + reset absensi + stok tetap dipertahankan.
